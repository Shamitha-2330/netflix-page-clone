# Netflix Landing Page

A responsive front-end clone of the Netflix landing page, built with HTML and CSS as a practice project.

> **Disclaimer:** This is an educational UI clone for practice only. It is not affiliated with, endorsed by, or connected to Netflix. It has no backend, and no data is collected, stored, or transmitted.

## Features

- Responsive layout that adapts from desktop to mobile screens
- Hero section with headline and call-to-action
- Feature sections in a clean, repeatable layout
- Footer with link columns
- Clean, semantic HTML and organised CSS

## Tech Stack

- HTML5
- CSS3 (Flexbox, media queries)

## What I Practiced

- Building a responsive landing page from a real-world design
- Flexbox for alignment and spacing
- Media queries for different screen sizes
- Structuring sections with semantic HTML

Adjust the tree to match your actual folder layout.

## Run Locally

```bash
git clone https://github.com/Shamitha-2330/netflix-landing-page.git
cd netflix-landing-page
```

Open `index.html` in your browser, or use the Live Server extension in VS Code.
